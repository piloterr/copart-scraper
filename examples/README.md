# Copart Scraper API – code examples

Examples for every Copart endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/lot.sh`](curl/lot.sh) | `bash lot.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/lot.php`](php/lot.php) | `php lot.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Lot.cs`](csharp/Lot.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/lot.go`](go/lot.go) | `go run lot.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/LotExample.java`](java/LotExample.java) | `java LotExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/lot.rb`](ruby/lot.rb) | `ruby lot.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/lot.mjs`](nodejs/lot.mjs) | `node lot.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
